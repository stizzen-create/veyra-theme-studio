# Veyra Theme Studio

Userscript for [Veyra](https://demonicscans.org/game_dash.php) by **UANM**.

## Install
1. Install [Tampermonkey](https://www.tampermonkey.net/) (PC: Chrome / Edge / Firefox; Android: Firefox).
2. Open **[veyra_theme_studio.user.js](https://raw.githubusercontent.com/stizzen-create/veyra-theme-studio/main/veyra_theme_studio.user.js)** and press *Install*. Updates arrive automatically.

## What it does
- **Themes** for every game page: 16 worlds with animated particles, fonts and frames, 4 of them with painted backgrounds.
- **Your own background**: upload an image and the interface adapts its colors to it.
- **Fonts, colors, glass, layout** dials.
- **Live mode**: boss spawn alerts, stamina mood, server day/night, parallax, particle words.
- **Redesigned pages** (each can be switched back to the original in the *Pages* tab): Inventory, Pets, Power Crystals, Black Merchant, Guild (dungeons first, with your loot status on recently ended instances), Gates.
- **Discord** #game-talk button, mini games (Tetris, Minesweeper, Starship Pinball).
