# Veyra Theme Studio

Userscript for [Veyra](https://demonicscans.org/game_dash.php) by **UANM**.

## Install
1. Install [Tampermonkey](https://www.tampermonkey.net/) (PC: Chrome / Edge / Firefox; Android: Firefox).
2. Open **[veyra_theme_studio.user.js](https://raw.githubusercontent.com/stizzen-create/veyra-theme-studio/main/veyra_theme_studio.user.js)** and press *Install*. Updates arrive automatically.

## What it does
- **Themes** for every game page: 68 worlds with animated particles, fonts and frames. 56 have painted backgrounds, including 20 *manga & manhwa* themes with their heroes (Berserk, One Piece, Naruto, Solo Leveling, Tower of God…) and 20 *fantasy lands* (Minas Tirith, Hogwarts, Hyrule, the Erdtree, Anor Londo, Skyrim, Laputa, Spirited Away…) and 12 *anime heroines* (Erza Scarlet, Mikasa, Saber, Yor Forger, Makima, Nico Robin, Motoko Kusanagi, Yoruichi, Esdeath, Cha Hae-In, Revy, Lisa Lisa).
- **No flicker** while you move between pages, and a **Home** button in the header.
- **Features tab**: every utility is optional and off until you switch it on.
- **Your own background**: upload an image and the interface adapts its colors to it. Every image you upload stays in a history, so you can switch back with one click.
- **Fonts, colors, glass, layout** dials.
- **Live mode**: boss spawn alerts, stamina mood, server day/night, parallax, particle words.
- **Redesigned pages** (each can be switched back to the original in the *Pages* tab): Inventory, Pets, Power Crystals, Black Merchant, Guild (dungeons first, with your loot status on recently ended instances), Gates, Blacksmith, and **Legendary Forge / Collections / Achievements** grouped by origin, with a summary of what you are still missing. Pets: drag and drop on mouse and touch; drag a pet out of its slot to remove it.
- **Discord** #game-talk button, **music player** (YouTube search and queue; searching needs your own free YouTube Data API key), mini games (Tetris, Minesweeper, Starship Pinball).
